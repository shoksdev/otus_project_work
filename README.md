Здравствуйте! Это моя проектная работа для курса OTUS Automation QA Engineer. 
Инструкция по запуску:
1) Склонировать проект;
2) Спулить образ Google Chrome ```docker pull selenoid/vnc:chrome_128.0```;
3) Запустить тесты командой ```docker compose up -d```;
4) Зайти в Jenkins по адресу localhost:8080 и авторизоваться;
5) Запустить тесты.
